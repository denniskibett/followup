# FollowUp - Government Enterprise Project Management System

## Overview
FollowUp is a comprehensive project management platform designed for government and enterprise environments with MCDA (Ministry, State Department, Agency) hierarchy support.

## Features

### Core Functionality
- **Multi-level MCDA Hierarchy** - Ministry → State Department → Agency structure
- **Real-time Project Tracking** - Live updates without page reloads using Alpine.js
- **Milestone Management** - Template-based milestones with custom additions
- **Task Assignment** - Assign tasks to team members with priority levels
- **Risk Registry** - Track and mitigate project risks
- **Dependency Management** - Map project dependencies and constraints
- **Funding Sources** - Track multiple funding sources and disbursements
- **Support Team** - Collaborative team management

### Technical Highlights
- **Frontend**: Alpine.js + Tailwind CSS
- **Backend**: Laravel 12.x
- **Database**: MySQL with Eloquent ORM
- **Real-time**: Event-driven architecture without page reloads
- **Rich Text**: Quill.js editor integration
- **Date Handling**: Flatpickr with timezone support
